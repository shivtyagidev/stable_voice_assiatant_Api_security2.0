Part 5 — Student MUST Do (Bot Cannot Do This)

Bot sirf technical detection se bachata hai — behavioral detection student ke haath mein hai:

1. Typing: Bot ka answer copy-paste mat karo — apne haath se type karo at normal human speed (40-60 WPM)
2. Code: Variable names rename karo, comments apne words mein likho — MOSS se bachne ka yahi tarika hai

5. MIC: Proctored exam mein kabhi MIC use mat karo — text input only
6. Build: Exam se pehle python build_exe.py chalao — python.exe visible hai abhi
7. Monitor: Single monitor only — dual monitor = instant flag on most platforms
8. AI text: LLM answers humanize karo before submitting — rephrasing zaruri hai
